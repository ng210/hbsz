TCP alapú kommunikáció WPF alkalmazásban

A projekt bemutatja
- a TcpClient és TcpServer használatát
- a kapcsolódás és az üzenetváltás kezelését

Futtatás
- indítsd el a programot kétszert
- az első példányban a File menüből válaszd a Host pontot
- a második példányban válaszd a Connect menüpontot
- az alsó beviteli mezőbe írt üzenet a Send gomb megnyomására a másik példányban megjelenik
